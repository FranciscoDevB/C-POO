# ExSeção 5 - Conta bancária

Exercício desenvolvido durante meus estudos de C# e Programação Orientada a Objetos (POO).

## 📚 Sobre o exercício

O programa simula uma conta bancária, permitindo cadastrar uma conta, informar um depósito inicial e realizar operações de depósito e saque.

A classe `Conta` é responsável por armazenar os dados da conta e realizar as operações bancárias.

## 🧠 Conceitos praticados

Neste exercício foram praticados:

- Criação de classes e objetos
- Construtores
- Propriedades
- Encapsulamento
- Modificadores de acesso (`private set`)
- Métodos
- Manipulação de dados pelo console
- Operações de depósito e saque

## 🏦 Funcionalidades

O programa permite:

1. Informar o número da conta
2. Informar o titular da conta
3. Informar se haverá depósito inicial
4. Realizar um depósito
5. Realizar um saque
6. Exibir os dados atualizados da conta

O saque possui uma taxa fixa de `5.00`.

## 💻 Tecnologias

- C#
- .NET
- Aplicação Console

## 🚀 Como executar

Clone o repositório e execute o projeto utilizando o Visual Studio, Visual Studio Code ou outra IDE compatível com .NET.
